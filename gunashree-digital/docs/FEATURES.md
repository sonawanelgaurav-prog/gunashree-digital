# Gunashree Digital Feature Map

## Admin
Dashboard, templates, categories, media library, users, designs, settings, publishing status, editable template schema.

## User app
Home, categories, template gallery, editor, photo upload, business/name fields, My Designs, profile, save/export entry points.

## Template schema
Each template stores canvas dimensions and JSON layers. Layer types can be `text` and `image`; the schema is intentionally extensible for shapes, SVG, stickers and locked layers.

## Suggested template fields
`{{NAME}}`, `{{BUSINESS_NAME}}`, `{{MOBILE}}`, `{{ADDRESS}}`, `{{PHOTO}}`, `{{LOGO}}`, `{{DATE}}`.
